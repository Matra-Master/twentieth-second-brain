[Clientside Scripting](https://hypermedia.systems/client-side-scripting/) 
El capítulo habla de librerías o formas de trabajar con _javascript client side_ que sean amigables para el estilo Hyperrmedia

- [VanillaJS](http://vanilla-js.com/), o lo mismo que, solo JS. El sitio proveé algo de boilerplate.
- [Alpine.js](https://alpinejs.dev/), una librería para agregar comportamiento directo a HTML, casi idéntico a lo que hace HTMX pero más orientado al client side.
- [_hyperscript](https://hyperscript.org/), un lenguaje de scripting para poner directo en el htmx pero que no usa sintaxis JS sino lenguaje quasi natural o.o
