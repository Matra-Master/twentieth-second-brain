En el capítulo de [Secrets of the HTMX Masters](https://hypermedia.systems/tricks-of-the-htmx-masters/) el autor menciona una sección sobre
ser pragmatico al decidir cuándo usar htmx y cuándo ir por la alternativa _"reactiva"_.
Plantea que hay patrones demasiado complejos para resolver sólo con hypermedia y menciona como caso obvio el de un spreadsheet online
y trabajable en tiempo real, como google Sheets. Una "webapp" como esa que verdaderamente tiene funcionalidades de algo nativo del OS es mucho
para este paradigma.
A lo que apunta es a conocer las debilidades de todas las herramientas y a saber muchas, para poder decidir de forma eficiente.
En otros capítulos muestran que se puede usar htmx al lado de frameworks, no opera con esos directamente pero es fácilmente inyectable en un
proyecto así que **es posible usarlo para las partes simples y usar react y otros para features muy cojudas**.
