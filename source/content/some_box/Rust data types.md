# Rust data types

## Scalar Types

A scalar type represets a single value.
There are four types:
  1. Integers
  1. Floating-point numbers
  1. Booleans
  1. Characters

### Integers

Number without fractionary part. Can be signed or unsigned

| Length  | Signed | Unsigned |
| ------- |:------:| -------: |
| 8-bit   | i8     | u8       |
| 16-bit  | i16    | u16      |
| 32-bit  | i32    | u32      |
| 64-bit  | i64    | u64      |
| arch    | isize  | usize    |
