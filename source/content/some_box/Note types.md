Types of notes for a zettelkasten

1._Fleeting notes_, which are only reminders of information, can be written in any kind of way and will end up in the trash within a day or two.

2._Permanent notes_, which will _never_ be thrown away and contain the necessary information in themselves in a permanently understandable way. They are always stored in the same way in the same place, either in the reference system or, written as if for print, in the slip-box.

3._Project notes_, which are only relevant to one particular project. They are kept within a project-specific folder and can be discarded or archived after the project is finished.
